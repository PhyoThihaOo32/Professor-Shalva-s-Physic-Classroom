# Professor Shalva’s cosmic classroom

The user-supplied space image is a palette, shape, and mood reference only. It is not embedded, displayed as a hero, or loaded as a wallpaper. The source file remains unchanged. Earlier `study-room-v2.png` and `lofi-cosmos.png` assets are retained as inactive design artifacts and are not requested by the app. The separately supplied welcome GIF is an explicit new embedded asset.

`app/cosmos.css` translates the reference into native interface design: slate-teal canvas with very subtle CSS color washes, turquoise primary controls, dusty violet correction controls, coral accents, circular active steps, rounded surfaces, and quiet mint work/composer paper. Welcome and role selection now embed their separately supplied space and astronaut GIFs, while the rest of the interface continues to use native CSS color and geometry. Manrope stays smooth throughout; the sidebar, continuous board/conversation interaction, reduced-motion behavior, and high-contrast focus mode remain.

## Full-page entry animations

The user-supplied `illustration space GIF by Two Dots.gif` is copied unchanged to `public/images/welcome-space.gif` (480 × 360, about 864 KB) and fills the welcome page. `fun lol GIF by Tomas Brunsdon.gif` is copied unchanged to `public/images/welcome-astronaut.gif` (480 × 360, about 1 MB) and fills role selection. Each scene is served locally through an unoptimized image inside a native picture element at the onboarding shell level. Responsive cover sizing fills the page, and a translucent scrim keeps the text readable. The role cards use lightly blurred translucent surfaces over the astronaut scene. These animations replace the corner ornaments; student selection uses its own evite rocket scene. Each picture selects its corresponding still PNG when `prefers-reduced-motion: reduce` is enabled. The original Desktop files remain unchanged.

The user-supplied `Outer Space GIF by evite.gif` is copied unchanged to `public/images/welcome-students.gif` (480 × 296) and fills the student-selection shell, with `welcome-students-still.png` for reduced motion. A compact header, three desktop cards or three mobile rows, and a single action row keep the cast and classroom action on one screen. Short screens show portrait, name, and personality label instead of the longer description; no overflow is forcibly hidden, so zoom and exceptionally small windows can still access content.
