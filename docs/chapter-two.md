# Chapter 2 classroom

Entering Classroom starts or resumes a saved conversation with the selected character. New classrooms use problem 5, “The drive home,” at guided difficulty with explicitly labeled mock responses. The main view shows only saved teacher–student exchanges and one guide/correction composer, without a repeated conversation heading, canned greeting, or automatic worked-step blocks. Messages and the input share a subdued conversation panel. “Show work board” opens the steps, checking, hints, revisions, and completion controls above the conversation; “Next step” reveals further work there. Finished sessions retain their saved conversation and review.

Library is a separate sidebar destination at `/library`. Its Chapter 2 shelf contains problems 5, 11, 13, 19, 21, 33, 41, 55, and 63. Problem 17 is listed as waiting for Fig. 2–40 and cannot start a fabricated graph exercise. The six original circular-motion problems remain in the Demos collection. Selecting a problem opens its question and optional difficulty/provider settings before creating a new session. The Classroom sidebar then resumes that chosen session.

The user supplied the exercise wording and screenshots. Problem 21's requested average acceleration was confirmed by the user. Problems 11 and 63 came from the supplied screenshots. Notation has been normalized, and explanatory steps and controlled mistakes were authored for this app.

Solutions use the given speeds, distances, and time intervals. Vertical-motion problems use `g = 9.8 m/s²`, ignore air resistance, and state their coordinate conventions. Problem 55 assumes the catch is at the release height; the height is measured above that point. Problem 41's fifth second is `[4, 5] s`. Problem 19 separates outgoing ball travel from the returning sound delay. Problem 13 has a native SVG position–time plot of the supplied polynomial; no arbitrary expression evaluation is used.

Reference solutions and approved error templates stay in `lib/chapter-two.ts`, on the server. Public chapter and exercise metadata does not expose final numerical targets, reference arrays, or error plans. The database seed inserts new immutable published versions while preserving existing sessions and original demo versions. The mock evaluator now understands seconds, metres, km/h, and negative numeric acceleration in addition to its previous units. Its limited, deterministic judgments remain formative and can be disputed. No paid OpenAI call is made when entering Classroom.

Connect an API key in Settings, then choose Live OpenAI in the classroom response selector. Live guidance can recalculate and save a new current step while retaining its Starting guide and revision history. The student receives public problem data and visible work, not the private solution or error plan. Mock mode remains the original deterministic guide.
