New sessions use version IDs `spongebob-v1`, `bart-v1`, and `stewie-v1`. Their teaching descriptions, greetings, and short responses are authored for this physics exercise. Physics errors and evaluation remain controlled by the reviewed problem templates.

Original persona versions remain available for existing sessions. Old student preferences and old problem/library links resolve to the corresponding current student for the next session; stored session identities and conversations are preserved.
